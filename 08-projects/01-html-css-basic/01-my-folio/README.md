# 🌐 MyFolio – Personal Portfolio Website

**MyFolio** is a clean, beginner-friendly personal portfolio project designed to showcase your profile, skills, and projects. Built with HTML and CSS, this project is ideal for frontend learners working on real-world layouts.

---

## 📸 GitHub Code & Live Preview

🔗 [MyFolio GitHub Repository](https://github.com/RayhanaAkterDev/Frontend-Bootcamp-2.0/tree/main/08-projects/01-html-css-basic/01-my-folio)  
🌍 [Live Preview on Netlify](https://my-web-folio.netlify.app/)

---

## ✨ Features

- Reusable and organized folder structure
- Clean and modern layout using CSS
- Fully responsive design
- Includes the following sections:
  - Hero
  - About Me
  - Services
  - Projects
  - Contact Form
  - Footer

---
