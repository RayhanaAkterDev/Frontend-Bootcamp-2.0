# CSS Backgrounds & Borders

> Tags: css-basics, css-backgrounds, css-borders  
> _Purpose:_ Learn and practice the core concepts of styling elements using background and border properties in CSS.

---

## 💡 My understanding

- **Background properties:** Control the appearance of an element’s background using color, images, gradients, size, position, and blending.
- **Border properties:** Define the edges of an element using width, color, line style, and corner rounding.

---

## 🔍 Key Tags & Purpose

### Background-related

- `background-color` → Sets a solid color as the background.
- `background-image` → Places an image or gradient as the background.
- `background-repeat` → Defines whether the background image repeats.
- `background-position` → Sets the background image position.
- `background-size` → Specifies the size of the background image.
- `background-blend-mode` → Blends background layers visually.

### Border-related

- `border` → Shorthand for border width, style, and color.
- `border-width` → Sets the border thickness.
- `border-style` → Defines the border line type (e.g., solid, dashed, double).
- `border-color` → Sets the border color.
- `border-radius` → Rounds the element’s corners.
