# CSS Typography

> Tags: css-basics, css-typography  
> _Purpose:_ Learn how to style and enhance text using font properties and spacing techniques for improved readability and visual design.

---

## 💡 My Understanding

In CSS, typography refers to the visual styling of text content. It plays a crucial role in readability, accessibility, and overall design aesthetics. CSS provides several properties to control how text appears on a webpage.

---

### Common Typography Properties

- `font-family` — Defines the typeface (e.g., serif, sans-serif, monospace)
- `font-size` — Sets the size of the text (e.g., 20px, 1.2em)
- `font-style` — Applies slanted text style such as italic or oblique
- `font-weight` — Controls the thickness of text (e.g., normal, bold, 700)
- `font-variant` — Enables alternate text forms like small-caps
- `letter-spacing` — Adjusts the space between individual characters
- `line-height` — Sets the vertical spacing between lines of text

---

## 🛠️ Common Utility Classes (with Purpose)

These are sample CSS classes that implement the typography properties above for quick styling.

- `.serif { font-family: serif; }` → Classic, formal font style
- `.sans-serif { font-family: sans-serif; }` → Clean, modern appearance
- `.monospace { font-family: monospace; }` → Code-style text
- `.italic { font-style: italic; }` → Slanted/italic text
- `.bold { font-weight: bold; }` → Emphasized bold text
- `.small-caps { font-variant: small-caps; }` → Uppercase in small-cap form
- `.font-size { font-size: 20px; }` → Sets a specific font size
- `.spaced { letter-spacing: 2px; line-height: 1.8; }` → Increases letter and line spacing
