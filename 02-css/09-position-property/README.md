# CSS Position Property

> Tags: css-basics, position-property  
> _Purpose:_ Understand and practice different CSS position property values and how they affect element layout.

---

## My understanding

- The `position` property controls how an element is positioned in the document.  
- Common values include `static`, `relative`, `absolute`, `fixed`, and `sticky`.  
- Each value changes how the element behaves and interacts with other elements on the page.

### 🔍 Key Tags & Purpose

- `position: static` → Default; normal flow  
- `position: relative` → Moves element relative to its normal position  
- `position: absolute` → Positioned to nearest ancestor with position  
- `position: fixed` → Pinned to viewport (always visible)  
- `position: sticky` → Sticks to top (or other edge) as you scroll  

---

> [!note]
>
> Helps practice controlling where elements appear on screen using positioning.  
> Sticky and fixed are useful for navbars, headers, etc.
