# CSS Display & Visibility

> Tags: css-basics, display, visibility  
> _Purpose:_ Understand and practice how CSS `display` and `visibility` properties affect element layout and visibility on a webpage.

---

## My understanding

- `display` controls how an element appears on the page — like block, inline, inline-block, or hidden.  
- `visibility` controls if an element is visible or hidden, but its space stays the same.

### 🔍 Key Tags & Purpose

- `display: block` → Element starts on a new line and takes full width  
- `display: inline` → Flows within text, no width/height applied  
- `display: inline-block` → Flows like inline, but allows box sizing  
- `display: none` → Hides the element and removes it from layout  
- `visibility: hidden` → Hides the element but keeps its space  
- `visibility: visible` → Default visibility

---

> [!note]
>
> - `display: none` removes the element completely from layout flow.  
> - `visibility: hidden` hides the element **but keeps its space**.  
> - Use `inline`, `block`, or `inline-block` to control how elements align and size.
> - Practice combining both for toggling UI elements like dropdowns, modals, or tooltips.
