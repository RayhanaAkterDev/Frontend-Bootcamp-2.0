# Flexbox Responsive

> **Tags**: css-layouts, flexbox, responsive-design  
> _**Purpose**_: Understand how Flexbox enables responsive layouts by aligning and distributing space among items within a container.

---

## My Understanding

1. **Flexbox (Flexible Box Layout)** is a one-dimensional layout system used to align items **horizontally or vertically**.
2. It makes layout design flexible by adjusting the **size, position, and spacing** of elements even when the viewport size changes.
3. Flexbox allows items to **wrap**, **grow**, or **shrink** depending on available space, making it perfect for **responsive design**.

---

> [!note]
>
> - The **flex container** is declared using `display: flex`.
> - By default, flex items are laid out in a **row**.
> - Use `flex-wrap: wrap` to allow items to shift to the next line on smaller screens.
> - `justify-content` controls horizontal alignment; `align-items` handles vertical alignment.

---

### 🔑 Key Tags & Purpose (🧠 Easy Revision)

| Tag / Term        | Purpose                                         |
|-------------------|-------------------------------------------------|
| `display: flex`   | Defines a flex container                        |
| `flex-wrap`       | Allows items to wrap into multiple rows         |
| `justify-content` | Controls horizontal spacing between flex items  |
| `align-items`     | Aligns items vertically inside the flex line    |
| `gap`             | Adds space between items without using margins  |
