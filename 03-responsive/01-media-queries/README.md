# CSS Media Queries

> Tags: responsive, media-query, css
> _Purpose_: Learn and practice how to use media queries to create responsive designs that adapt to different screen sizes.

---

## My understanding

- Media queries allow CSS to adapt styles based on the characteristics of the device or viewport, like screen width or orientation.
- They are written using the @media rule and help apply different styles for different screen sizes (e.g., mobile, tablet, desktop).
- A responsive design improves user experience across devices without needing multiple versions of the same page.

---

> [!note]
>
> - Common conditions used in media queries include max-width, min-width, orientation, and resolution.
> - Use max-width for a mobile-first approach.
> - You can include multiple breakpoints to style for various devices.

### Example Syntax:

```css
@media (max-width: 768px) {
  /* styles for screens 768px or smaller */
}
```
